# JeuDevinettes

## Description
Jeu de devinettes en Java où l'ordinateur génère un nombre
aléatoire entre 1 et 100 et l'utilisateur doit le deviner
en 10 essais maximum.

## Structure du projet
- "Main.java" : Classe principale contenant le programme

## Fonctionnalités
- Génération d'un nombre aléatoire entre 1 et 100
- 10 essais maximum pour deviner le nombre
- Indices après chaque essai raté ("votre nombre est trop grand/petit")
- Message de félicitations si l'utilisateur gagne
- Message de défaite si les 10 essais sont épuisés

## Comment exécuter
1. Cloner le dépôt
2. Ouvrir le projet dans IntelliJ IDEA
3. Exécuter la classe "Main.java"
4. Entrer un nombre entre 1 et 100 dans la console
